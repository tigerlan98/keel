## 4. 最新评审结论（必须遵守）

`06` 的 P-01～P-07 已确认，摘要如下：

1. **资源与参数由 Flyway 迁移维护**：v1 不提供后台新增/删除接口，后台只更新展示属性或参数值。
2. **停用资源需无启用子资源**：停用目录/菜单前校验，存在启用子资源返回 409 `IAM_RESOURCE_HAS_ENABLED_CHILDREN`。
3. **移除仪表盘菜单**：Admin 登录后跳转第一个有权限的菜单。
4. **`SUPER_ADMIN` 不可禁用**：同时不可删除、不可修改 code。
5. **`API` 为预留资源类型**：当前不种子化，接口鉴权复用 `MENU` / `BUTTON` 的权限码。
6. **资源父级限制**：父级只能是根、`DIRECTORY` 或 `MENU`；禁止成环。
7. **`schema.sql` 与 03 一致**：实际执行以 Flyway 为准；仓库内未发现物理外键。

## 5. 关键技术决策

| 领域 | 结论 |
|---|---|
| 运行时 | Java 25 LTS、Spring Boot 4.1.x |
| 构建 | Maven 单体多模块，9 个模块 |
| 坐标 | groupId `io.github.keel`，artifactId 前缀 `keel-`，版本 `1.0.0`，包根 `io.github.keel` |
| 持久层 | MySQL 8、MyBatis-Plus 3.5.15+、Flyway |
| 数据库规范 | 自增 `BIGINT`；`DATETIME(3)`；`Asia/Shanghai` 本地时区（已记录的例外）；无物理外键；无逻辑删除 |
| 认证 | Spring Security 7 无状态 + opaque token + Redis；Web Cookie / App Bearer；CSRF 双模式 |
| 会话 | 按设备单会话；Web 空闲 30 分钟 / 绝对 12 小时；App 7 天 / 30 天 |
| 权限 | 统一资源树、RBAC、多角色、扁平角色、`SUPER_ADMIN` 绕过 |
| 缓存 | Redis：权限缓存、系统参数缓存（TTL 30 分钟，更新即删除） |
| API | `/api/v1`；`{ code, message, data }`；`X-Request-Id` 头；字符串错误码；`page` 1 起、`size` 最大 100 |
| 前端 | Admin / Portal 位于 `frontend/` 子目录；Vue 3 + TypeScript + Vite |
| Admin UI | shadcn-vue + Tailwind v4 + VeeValidate/Zod + Lucide |
| Portal UI | shadcn-vue + Tailwind，与 Admin 同一设计语言 |
| 测试 | 后端 JUnit 5 + Testcontainers + ArchUnit；前端仅 Playwright |
| 运维 | Actuator 仅暴露 `/actuator/health` |
| CI | 暂不绑定平台，使用平台无关命令 |
| 清理锁 | 单实例不加锁；多实例前引入 ShedLock |
