# 角色管理界面复刻

用户确认完整复刻本地 scaffold-vue 参考项目的列表、矩阵、溯源界面，沿用 Keel 的角色、资源与鉴权规则，不新增后端接口、依赖、数据权限或导出能力。

- 列表：珍珠玻璃筛选区、角色名称与编码组合列、描述、排序、状态、创建时间及操作；原有创建、编辑、删除和授权继续使用现有接口。
- 矩阵：资源树为行、角色为列；支持折叠、授权差异、重置、逐角色保存。超级管理员列表示绕过授权，不写入授权记录。按实际勾选提交，保留现有显式资源授权语义，不推导数据权限。失败时保留尚未保存的角色改动，成功提交的角色更新基线；离开时确认放弃改动。
- 溯源：珍珠球、三类表盘、真实实体辐射点位、用户—角色—资源关系、统计、实体下钻与本地规则查询。统计基于完整分页读取的真实数据；全部读取完成前不呈现全局计数。停用用户、停用角色和停用资源不能作为有效权限来源；超级管理员按项目绕过权限规则单独标识。
- 页面访问仍需 `iam:role:list`；资源关系读取需 `iam:resource:list`，用户关系读取需 `iam:user:list`；缺少读取权限时明确提示并不发对应请求、不将不可见数据当成 0。写矩阵与授权需 `iam:role:assign-resource`。
- 本地提问基于当前可读关系进行名称、编码、权限动作匹配，不接入外部模型、不虚构回答。不提供真实用户计数时隐藏用户相关的完整性结论。
- 状态：加载、失败重试、空数据、无权限、未保存、部分保存失败；桌面与窄屏适配；键盘操作、减少动态效果与暂停/重播。

验证使用现有前端服务和 Playwright 模拟接口，不启动应用或 Docker，不修改真实授权。
