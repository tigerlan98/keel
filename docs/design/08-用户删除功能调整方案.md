## 已确认的删除方案

- 提供永久删除用户的能力，不以禁用或逻辑删除替代。
- 新增 `DELETE /api/v1/admin/iam/users/{id}?version={version}`，权限码为 `iam:user:delete`，成功返回 204；id 为正数，version 为来自详情的必填非负整数。
- 禁止删除当前登录账号、拥有 `SUPER_ADMIN` 角色的账号；服务端强制校验。
- 在同一数据库事务中删除用户与用户角色关联；不删除角色、部门或历史审计日志。
- 删除、分配角色按用户行锁串行化；删除校验最新版本与角色保护。登录使用用户共享行锁与删除互斥，避免账号删除后并发签发新会话。删除时吊销全部登录会话并清理用户权限缓存；Redis 清理失败时回滚数据库删除（已经失效的会话不恢复）。
- 前端使用垃圾桶图标和二次确认，明确提示永久删除；提交中防止重复操作，成功后刷新列表，末页为空时回到上一页，失败时保留错误反馈。
- 使用新增 V9006 权限种子按业务 code 幂等写入 `iam:user:delete`；不自动授予普通角色，不修改已执行迁移或数据库结构。通过正式导出流程同步 OpenAPI 和生成类型。
